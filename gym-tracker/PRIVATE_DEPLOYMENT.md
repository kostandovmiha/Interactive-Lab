# Gym Tracker — приватний реліз

## Поточний стан
- Прототип: `gym-tracker/index.html`, гілка `feature/gym-tracker-private-gate`.
- Не зливати гілку в `main`, поки не налаштовано приватний хостинг.
- `Interactive-Lab` є публічним GitHub-репозиторієм. GitHub Pages не приховує окремий шлях.
- Локальне збереження: `localStorage` у браузері. Немає серверної синхронізації та резервної копії.
- Поточний прототип містить лише шаблонні вправи/ваги з попереднього журналу, без облікових даних.

## Безпечна архітектура
1. Залишити публічний Interactive-Lab як навігаційний каталог.
2. Винести приватний Gym Tracker в окремий **приватний** репозиторій і розгортати на хостингу з перевіркою доступу **до видачі HTML/JS** (наприклад Cloudflare Access + Cloudflare Pages/Workers).
3. Увімкнути доступ тільки для підтвердженої адреси власника. Не покладатися на приховане посилання, клієнтський пароль або Firebase Auth як захист статичних HTML/JS.
4. Після підтвердження приватного URL додати в каталог Interactive-Lab картку Gym Tracker, що веде на приватний домен.
5. Для синхронізації журналу Google Sheets потрібен окремий серверний компонент із контрольованою авторизацією. Не записувати токени/ключі у фронтенд.
6. Після перевірки авторизації, резервного копіювання й доступу з Android додати PWA/offline.

## Критерії приймання
- Анонімний користувач не отримує HTML/JS Gym Tracker.
- Лише власник може увійти; іншим відмовлено.
- Записи не видно іншим користувачам або через публічний репозиторій.
- Дані не втрачаються при оновленні вкладки.
- Звіт можна експортувати до наступного тренування.
- Синхронізацію Google Sheets вмикати лише після перевірки безпеки.

## Потрібна дія власника
Підключити/авторизувати обраний захищений хостинг та підтвердити адресу Google/email, якій дозволено доступ. Не надсилати пароль чи токени в чат.

Як додати аудіозразки ElevenLabs?

У ElevenLabs Voice Library ↗ послухай жіночі голоси й обери кілька, які доступні твоєму тарифу. Натисни «Копіювати фразу», встав її в Text to Speech ↗, згенеруй і збережи кожен варіант у MP3.

Натисни «Додати аудіо» у відповідній картці або просто перетягни файл на неї. Зразки зберігаються тільки в цьому браузері, а не завантажуються на сервер. Познач найкращий голос зірочками й кнопкою «Обрати».

Також підготовлено захищений GitHub Actions workflow для автоматичного створення зразків ElevenLabs після налаштування API-ключа. У безкоштовному тарифі Voice Library через API недоступна; через сайт можна використовувати доступні безкоштовні голоси.

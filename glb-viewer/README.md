# GLB Viewer · Interactive Lab

Окремий браузерний переглядач **локальних файлів .glb**, доступний за шляхом `glb-viewer/` після публікації відповідної гілки.

## Як користуватися

1. Відкрийте `glb-viewer/` із головної сторінки Interactive Lab.
2. Натисніть **Обрати GLB-файл** або перетягніть файл у вікно 3D.
3. Обертайте камеру лівою кнопкою, переміщуйте правою, масштабуйте колесом.
4. Перемикайте ракурси, сітку, осі, wireframe, фон та експозицію.
5. Якщо GLB містить анімацію, виберіть кліп, відтворіть або поставте на паузу.
6. За потреби збережіть PNG поточного ракурсу.

## Технічні деталі

- GitHub Pages, HTML + CSS + Three.js `0.180.0`, без бекенда чи завантаження моделей у сховище.
- Three.js, Draco, Meshopt, KTX2/BasisU беруться з CDN під час роботи сторінки.
- Підтримуються GLB 2.0 з вбудованою геометрією й текстурами; зовнішні URI у `buffers` та `images` заборонені, щоб локальний файл не ініціював мережевих звернень.
- Максимальний розмір файлу: 200 МБ (фактичні вимоги до оперативної та відеопам'яті можуть бути значно більші).
- PBR-матеріали освітлюються `RoomEnvironment`; відображення не гарантує тотожності V-Ray, Blender чи інших рендерів.
- Для відстеження габаритів одиниці беруться з GLB; сам переглядач не перетворює їх на сантиметри.
- Джерело файлу не зберігається між оновленнями сторінки.

## Мінімальна ручна перевірка

- [ ] Відкрити простий GLB без текстур та перевірити обертання, fit, ракурси й сітку.
- [ ] Відкрити текстурований GLB та перевірити матеріали, фон, експозицію.
- [ ] Відкрити GLB з анімацією; перевірити кліпи, паузу.
- [ ] Перевірити DRACO / Meshopt / KTX2 на тестових файлах.
- [ ] Перетягнути файл, потім замінити його іншим; переконатися, що стара модель зникла.
- [ ] Завантажити не-GLB і GLB із зовнішньою текстурою та перевірити повідомлення про помилки.
- [ ] Перевірити збереження PNG і мобільний екран.

> Живий WebGL і декодери потребують перевірки у браузері після публікації. Ці тести не виконуються під час самого коміту.

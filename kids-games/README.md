# Kids Playground · Голосові підказки

Дитяча гра **«Лопни кульку»** використовує **28 заздалегідь створених українських аудіозаписів** у `audio/*.ogg`.

- Озвучення не залежить від Web Speech API або встановлених голосів браузера.
- Відтворення працює у Chrome на Windows та Android за умови підтримки Ogg/Opus.
- Файли Ogg/Opus невеликі та кешуються сервіс-воркером для гри офлайн.
- Голос і звукові ефекти регулюються окремо; загальна кнопка звуку вимикає обидва.
- У режимі «Вивчаємо кольори» доступні 9 кольорів (червоний, жовтий, синій, зелений, помаранчевий, фіолетовий, рожевий, бірюзовий, коричневий); для кожного є фрази «Знайди…» та «Шукай…». Є кнопка повторення підказки та налаштування автоозвучення.
- Коли голос неможливо відтворити, у грі показується діагностичне повідомлення.

## Авторство голосу

Використано модель **Tetiana — uk_UA-tetiana-high**, створену **Roman Stasyshyn**.
Джерело: https://huggingface.co/RomanStasyshyn/uk_UA-tetiana-high .
**Ліцензія моделі: Apache-2.0.** У вебгру вбудовано лише синтезовані короткі аудіозаписи, саму модель не включено.

### Як відтворити аудіофайли

Workflow `.github/workflows/build-kids-voice.yml` запускає `scripts/generate_kids_voice.py` у GitHub Actions. Скрипт завантажує модель, генерує лише відсутні WAV-фрази, конвертує у Ogg/Opus та записує готові кліпи в `kids-games/audio/`.

## Перевірка

1. Відкрити `/kids-games/#balloons` у Chrome на Windows та Android.
2. Натиснути «🔁 Повторити підказку» — повинно прозвучати речення українською.
3. Увімкнути «🎨 Вивчаємо кольори» — озвучуються команди для дев’яти кольорів. Перевірити обидві фрази для нових п’яти.
4. Перевірити кнопки «🗣️ Голос», «🔊 Звук» та автовідтворення.
5. Після повного завантаження сторінки перевірити гру в режимі офлайн.

Примітка: голос Tetiana/Piper — тимчасова українська озвучка. Для фінальної заміни на ElevenLabs/Google потрібні надані або згенеровані з відповідною ліцензією аудіофайли. Перед публічним використанням бажано прослухати записи та перевірити наголоси.

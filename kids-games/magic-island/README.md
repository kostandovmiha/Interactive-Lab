# Мій чарівний острів

Тиха 3D-гра українською. Відкрий острів, торкнися зайчика, дерева чи будиночка й подивися, як вони оживають. Гра запускається одразу й працює без облікового запису.

## Керування

- Обери дерево, будиночок або зайчика й торкнися галявини. Кільця показують кілька вільних місць. Предмет можна поставити в будь-якій придатній точці. Берег, ставок, стежка й зайняті ділянки залишаються вільними.
- Торкнися дерева, щоб воно похитнулося, зайчика, щоб він підстрибнув, або будиночка, щоб змінити світло у вікнах.
- Проведи пальцем або перетягни мишею по горизонталі, щоб повернути острів. Розведи два пальці, прокрути коліщатко над ігровим полем або натисни «+», щоб наблизити. Кнопка з рамкою повертає камеру до загального плану. Поворот і масштаб мають обмеження.
- Кнопки камери доступні з клавіатури. Для розстановки сфокусуй ігрове поле, переміщуй позначку стрілками й натискай Enter або пробіл. Escape скасовує вибір.
- Додавання автоматично зберігаються в цьому браузері через `localStorage`. Кнопка «Очистити» відкриває підтвердження й видаляє лише додані предмети.

## Структура й ліцензії

- `camera.js` кадрує сцену та обробляє жести й кнопки камери. `game.js` керує взаємодіями, циклом рендера та збереженням.
- `world.js` будує рельєф, воду, стежку, рослини й декорації. `models.js` створює моделі, об’єднує їхні деталі за матеріалами й повторно використовує геометрію.
- Геометрію, матеріали, шейдери й піктограми створено для цієї гри. Зовнішніх моделей, текстур, шрифтів чи аудіофайлів гра не завантажує.
- У `vendor/` збережено мінімізовані ES-модулі [Three.js 0.183.2](https://github.com/mrdoob/three.js/tree/r183) з [ліцензією MIT](./vendor/three-LICENSE.txt). Імпорт `three/core` у модулі замінено відносним шляхом для статичного хостингу.
- `review/` містить скриншоти Chromium для перегляду в PR. Під час гри вони не завантажуються.

## Локальна перевірка

У корені репозиторію виконай:

```sh
python3 -m http.server 4173
node --check kids-games/magic-island/game.js
node --check kids-games/magic-island/camera.js
node --check kids-games/magic-island/world.js
node --check kids-games/magic-island/models.js
```

Відкрий `http://localhost:4173/kids-games/` і перейди на острів через каталог. Перевір режими 390×844 та 844×390 з емуляцією дотику і 1280×800 з мишею. Спробуй поставити кожен із трьох предметів на галявину, а також торкнутися води та вже зайнятого місця під час розстановки. Перезавантаж сторінку, скасуй очищення, підтвердь очищення, поверни камеру й повернися до каталогу. З вибраним предметом проведи пальцем по сцені та наблизь її двома пальцями. Розстановка має зберегтися, а кнопка з рамкою — відновити загальний план. Перевір консоль браузера.

На GitHub Pages гра працює під `/Interactive-Lab/kids-games/magic-island/` завдяки відносним шляхам. Окреме офлайн-встановлення гри не передбачене.

## Обмеження та наступні художні поліпшення

Потрібен браузер із WebGL 2. Розстановка має обмеження до 18 доданих предметів і залежить від вільної площі. Рендерер обмежує роздільність і зупиняється в прихованій вкладці. На сенсорних пристроях тривалий спад частоти кадрів додатково знижує роздільність. Поверхні моделей із пласким кольором об’єднані за допомогою кольорів вершин. За системного налаштування зменшеного руху сцена статична, вікна реагують, а камера повертається одразу. Перша версія без звуку.

Для наступного художнього проходу можна додати більше сезонних силуетів дерев і ще один варіант покрівлі. Перед збільшенням деталізації варто виміряти частоту кадрів на фізичних Android-телефонах.

Нотатки синхронізуються з Google Drive після підключення. Можна експортувати резервну копію.

Налаштування Google Drive

Для безпечного вибору папки потрібні ідентифікатори Google Cloud. Паролі й Client Secret не вводь. OAuth дозвіл: drive.file, без доступу до всього Диска.

У Google Cloud потрібно увімкнути Drive API і Google Picker API, створити OAuth web client та додати дозволений JavaScript origin https://kostandovmiha.github.io. Якщо застосунок у режимі Testing, додай свою Google-пошту до Test users. API key обмеж за доменами GitHub Pages і docs.google.com та API Picker/Drive.

Вибери папку цього напряму на Google Drive. Кожен напрям зберігає власний course.json, а скріншоти зберігаються окремими файлами. OAuth-клієнт спільний для напрямів.

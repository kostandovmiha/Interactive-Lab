# Learning Lab v1.2

Навчальний записник у складі [Interactive Lab](../README.md).

## Файли

- `index.html` — бібліотека напрямів, створення власних напрямів та пошук нотаток по Google Drive.
- `workspace.html?project=rebelway` — курс Rebelway Cinematic Lighting.
- `workspace.html?project=copernicus` — самостійне вивчення Houdini Copernicus.
- `workspace.html?project=custom-…` — власні напрями з локального каталогу.

## Дані та сумісність

**Google Drive — основне сховище.** Кожен напрям має окрему вибрану користувачем папку Google Drive та свій `course.json`; скріншоти зберігаються окремими файлами. Перед редагуванням важливих нотаток переконайся, що підключення виконано та з’явився статус «Збережено на Google Drive». Доступ до Drive здійснюється через Google Identity Services і Google Picker із дозволом `drive.file`.

- Для Rebelway навмисно використовується **старий** ключ конфігурації `ll-config-v1`, щоб не загубити вибір папки та не мігрувати чинний `course.json`.
- Інші напрями використовують власні ключі `ll-config-v2-<id>`. Публічні параметри OAuth Client ID / API Key / Project Number можна успадкувати з уже заповнених налаштувань; папки не успадковуються.
- Формат `course.json` має `schema: 1` з масивом `weeks` (для Copernicus це теми) і масивом `lessons` (для Copernicus це матеріали), кожен із `notes`. Додаткові необов'язкові поля матеріалу: `source`, `url`, `version`.
- Власні напрями у бібліотеці поки що зберігаються в **локальному каталозі браузера** (`ll-catalog-v2`); при відкритті на новому пристрої їх доведеться додати знову, тоді вибрати ті самі папки Drive. Нотатки з Google Drive від цього не видаляються.
- Ідентифікатори особистих папок Drive не зберігаються у вихідному коді сайту.
- Немає бекенду й автоматичного об’єднання одночасних редагувань з двох вкладок. Рекомендується одна активна вкладка на один напрям.
- Експорт JSON містить посилання на ID скріншотів на Drive, але **не включає байти зображень**. Не вважати його повним offline-архівом усіх файлів.

## Перевірка в браузері

1. Відкрити бібліотеку `/learning-lab/`, перевірити дві картки.
2. Відкрити Rebelway, підключити Google Drive, перевірити раніше створені уроки й нотатки. Не створювати новий порожній файл поверх наявного.
3. Відкрити Copernicus, підключити той самий Google Cloud OAuth та вибрати окрему папку *Houdini — Copernicus*. Перевірити шість стартових тем.
4. Додати матеріал у тему: назву, джерело, URL, версію Houdini і нотатку з тегом. Дочекатися «Збережено на Google Drive».
5. Оновити сторінку і переконатися, що всі дані прочитано назад. У папці Copernicus повинен з’явитися її власний `course.json`.
6. На головній сторінці Learning Lab пошукати у Google Drive ключове слово або тег та відкрити відповідний результат.

## Форматування нотаток (v1.3)

Вибери текст усередині нотатки й скористайся панеллю форматування. Доступні **напівжирний**, *курсив*, підкреслення, закреслення, колір тексту, кольорова підсвітка й очищення форматування.

- `Ctrl+B` / `Cmd+B` — напівжирний.
- `Ctrl+I` / `Cmd+I` — курсив.
- `Ctrl+U` / `Cmd+U` — підкреслення.
- `Ctrl+Shift+X` (додатково `Alt+Shift+5`) — закреслення.
- Колір тексту та підсвітка — через випадаючі палітри на панелі.
- «Очистити» — прибирає форматування виділеного тексту.

Зворотна сумісність: наявне поле `notes[].text` залишається звичайним текстом для пошуку. Відформатоване подання необов'язково записується в `notes[].html` і очищається від небезпечних HTML-тегів та довільних стилів перед збереженням/відображенням. Старі нотатки без `html` відкриваються як звичайний текст. Вставлення тексту з інших програм відбувається без стороннього форматування; скріншоти, як і раніше, можна вставляти через буфер обміну. Markdown-експорт зберігає нестандартні стилі через дозволений HTML у Markdown.

Зараз редактор спирається на браузерну команду `execCommand` для збереження нативних виділення та історії undo. Це застарілий, але ще доступний механізм у сучасному Chromium; поведінку в інших браузерах слід перевіряти окремо.
